# pip constraints for running PaddleOCR on AMD GPUs with ROCm.
#
# Installing "paddleocr[doc-parser]" can pull in the CUDA builds of PaddlePaddle
# (paddlepaddle, paddlepaddle-gpu) or the NVIDIA CUDA runtime wheels. Those would
# replace the ROCm build of PaddlePaddle and stop PaddleOCR from using the AMD
# GPU. Each such wheel is pinned to ==0 here so that it cannot be installed.
#
# Usage, from the repository root:
#   pip install -e ".[doc-parser]" -c deploy/accelerators/amd-gpu/amd-constraints.txt
